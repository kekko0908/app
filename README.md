# App Gestione Patrimonio

Questa semplice applicazione web permette di creare e gestire conti con un nome e dei tag associati. I dati sono salvati nel `localStorage` del browser, quindi non è richiesto alcun backend.

## Come usare

1. Apri `index.html` in un browser moderno.
2. Compila il form indicando il **Nome del Conto** e, facoltativamente, una serie di **tag** separati da virgola.
3. Clicca su **Aggiungi Conto** per visualizzare il nuovo conto nella lista.
4. Puoi eliminare un conto tramite il pulsante *Elimina* all'interno della relativa card.

L'interfaccia è basata su [Bootstrap 5](https://getbootstrap.com/).
